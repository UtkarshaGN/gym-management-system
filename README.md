High Street Gym (Backend)

A full-stack gym management web application with three user roles: Member, Trainer, and Admin. Users can securely sign up, log in, and manage gym activities through role-based features. The platform includes workout session bookings, blog posting, user management, and activity management.

Features
Member
Sign up, login, and logout
Book and manage workout sessions
Create and delete blog posts
Trainer
Login and logout
Create and manage workout sessions
Create and delete fitness posts
Admin
Login and logout
Create, edit, and delete sessions
Manage bookings, users, activities, and locations
Technologies Used
Node.js
Express.js
MySQL
bcryptjs
cors
HTML
EJS
Tailwind CSS
